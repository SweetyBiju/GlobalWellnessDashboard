# GlobalWellnessDashboard
Global Health and Prosperity Insights Dashboard
Welcome to the Global Health and Prosperity Insights Dashboard, an interactive Excel-based tool designed to visualize and analyze key metrics related to global health outcomes and economic prosperity. This dashboard provides intuitive insights through dynamic charts, slicers, and pivot tables, making it ideal for researchers, policymakers, and data enthusiasts.

**Features**

1. Interactive Visualizations: Explore trends in health metrics (e.g., life expectancy, HIV prevalence) and prosperity indicators (e.g., GDP per capita) using dynamic charts.
2. Slicers and Filters: Easily filter data by region, year (2000-2022), or countries to focus on areas of interest.
3. Pivot Tables: Summarize and analyze large datasets with customizable pivot tables.
4. User-Friendly Design: Clean layout with clear labels and instructions for seamless navigation.

**Dataset**

The dashboard is built using a dataset 'raw_data_unesco.xlsx' included in this repository. The data aggregates publicly available global health and economic indicators from the UNESCO web browser.

**How to Use**

*Download the Dashboard:*
Clone this repository or download dashboard.xlsx from the repository.

*Open in Excel:*
Open dashboard.xlsx in Microsoft Excel (2016 or later recommended).
Ensure macros are enabled if prompted (for advanced interactivity).

*Explore the Dashboard:*
Use slicers to filter by region, year, or country.
Interact with charts and pivot tables to uncover insights.

*Requirements*
Software: Microsoft Excel 2016 or later (Windows or Mac).
Dependencies: None; the dashboard is self-contained.
